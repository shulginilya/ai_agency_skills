# Docs

Reference material that isn't a runtime skill: playbooks, research notes,
client context, decisions, anything worth keeping but not worth loading into an
agent's context automatically.

No required structure. Add a line here when you add a file.

## Suggested conventions

- One topic per file, kebab-case filenames.
- Start each file with an `# H1` title and a one-line summary.
- If a doc grows into something an agent should act on, promote it to a skill
  under `skills/`.
